Email Triage Dashboard — Architecture

Gmail inbox → AI classification → department-scoped dashboard, with full audit trail

The pipeline

  • • Gmail API pulls inbox via OAuth2 (one-time consent, auto-refresh)
  • • Each unique email saved as an immutable RawEmail row
  • • Groq LLM classifies: department + confidence + summary + reasoning
  • • Confidence < 60% or no department match → "Needs Review" queue
  • • Otherwise auto-routed into that department's ticket queue

Security & access

  • • Passwords stored as BCrypt hashes, never plaintext
  • • JWT bearer tokens carry role + departmentId claims
  • • API filters every query by the caller's department
  • • SuperAdmin role bypasses the filter to see everything
  • • Gmail/Groq secrets kept in git-ignored config, never committed

Auditability

  • • RawEmail rows are never edited — always the ground truth
  • • Every status change, reassignment, and AI classification
  • is written to an append-only AuditLog tied to its ticket
  • • "View original email" in the UI replays the raw source
  • • Full trail: who/what changed a ticket, and when
